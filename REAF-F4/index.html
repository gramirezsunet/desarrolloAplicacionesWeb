Instrucciones de Trabajo y Directrices para la Fase 4

Bienvenido a la plataforma interactiva REAF-F4. Aquí encontrarás las recomendaciones personalizadas para la construcción de tu Frontend en React 18, la integración completa End-to-End con tu API en .NET 10 y la preparación para la defensa presencial en aula.

Flujo de Trabajo Sugerido para los Equipos

1

1. Explorar el Modelo

Ingresen a la pestaña Grupos & Modelos, seleccionen su proyecto y analicen las brechas de negocio y componentes estrella propuestos.

2

2. Diseñar la UI React 18

Construyan la interfaz gráfica aplicando diseño responsivo (*Mobile First*), componentes modulares y estados visuales de carga (*Skeletons*).

3

3. Integración E2E & JWT

Conecten la UI con los endpoints de su API en .NET 10 mediante Axios, gestionando tokens JWT Bearer y capturando errores bajo el estándar RFC 7807.

4

4. Validar con Checklist

Completen los 10 puntos del Checklist Transversal y ensayen una demostración de flujo completo para la defensa presencial en aula.

Criterios de Aprobación para la Fase 4

1. Frontend Desacoplado & Moderno

Desarrollado en React 18 / Vite / TypeScript con Tailwind CSS, modularizado en componentes limpios y sin código espagueti.

2. Integración End-to-End Real

Todo dato visualizado debe guardarse y consumirse desde la base de datos PostgreSQL mediante la API .NET 10 (sin arreglos estáticos en memoria).

3. Manejo de Errores RFC 7807

Las alertas Toast y validaciones visuales deben capturar el formato estructurado application/problem+json emitido por el backend.

4. Seguridad JWT y Control por Roles

Protección de rutas privadas en React mediante *Guards* que verifiquen el rol del usuario autenticado (Admin vs. Operador/Empleado).
